# ととのい帳 探すタブ・質感素材 第2弾

Issue #24の量産第2弾。公開中のalpha.3を基準に、地図の情報と操作を邪魔しない静かな素材へ揃えています。`totonoi/index.html`への組み込みは含みません。

## 納品物

| ファイル | サイズ | 意図 |
| --- | ---: | --- |
| `map-paper.webp` | 256x256 | 暖色クリームの古紙。繊維ムラとごく薄い経年斑のみ。方眼なし、四辺シーム差分0。 |
| `ft-snow.webp` | 256x256 | シングル水風呂。六花を太い手彫り線へ単純化。 |
| `ft-moon.webp` | 256x256 | 深夜営業。欠け月と一つ星で、小サイズでも判別可能。 |
| `ft-oke.webp` | 256x256 | 銭湯。木桶の箍と縦板を太線で表現。 |
| `ft-key.webp` | 256x256 | 予約制。丸い鍵頭と段付きの鍵先。 |
| `map-pin-concept.webp` | 960x360 | 地図ピン3態の意匠見本。左から訪問済・未訪問・行きたい。実装素材ではなく参照用。 |

## 組み込みメモ

- 地図下地は `background-color: #FBF1DC` と `map-paper.webp` を重ね、`background-repeat: repeat` で使う。
- 方眼は既存のCSS/SVG描画を維持し、テクスチャ画像へ焼き込まない。
- 特性アイコン4種はRGB黒1色＋アルファ。`mask-image` / `-webkit-mask-image` と `background: currentColor` で朱・こげ茶・金へ染める。
- アイコンは第1弾タブアイコンと同じ16px前後の主線量を基準にした。リストでは16-18px、チップでは14-16pxを推奨。
- ピン案は「輪郭を少し揺らした大きな滴型」を共通シルエットにし、訪問済=朱ベタ、未訪問=紙色＋こげ茶輪郭、行きたい=紙色＋金輪郭＋星で区別する。
- ピンの傾きは施設IDハッシュで`-3deg`から`3deg`程度に限定すると、手押し感とタップ精度を両立できる。

## 再生成

- `source/generate-map-paper.sh` はImageMagickを使用する。128px原画を左右・上下へ鏡像接続するため、256px出力の境界画素は完全一致する。
- アイコンとピン見本は`source/`のSVG原版からWebPへ書き出す。
