# スタンプラリー復活案 — 紗也乃さん向け

Issue #24 コメント `5385866666` のビジュアル検討です。`visual-directions.html` と390×844の3カットで、記録ファーストを壊さずに「枠を埋める楽しみ」を戻す境界を比較します。

## 納品物

- `01-shelf-opt-in.png`：A案、390×844
- `02-bird-reveal.png`：B案、390×844
- `03-separate-470s.png`：C案、390×844
- `visual-directions.html`：3案を再描画できるHTML。`?cut=direction-a` / `direction-b` / `direction-c` で単独表示

## 結論

**A「棚の奥に、めぐり帳」を推奨します。** 帳・探す・記録には進捗を出さず、棚の県ページで本人が「めぐりをひらく」を選んだ後だけ残り枠を見せます。ラリーを探しに来た人には届き、日々の記録を課題へ変えません。5つ目のタブは増やしません。

## 3方向

### A. 棚の奥に、めぐり帳（推奨）

- 置き場所：`棚 > 地方 > 県` の中だけ
- 見せる時：本人が県ごとに「めぐりをひらく」を選んだ後は常設
- 進捗：墨の数字と未押印の伏せ判。途中で金は使わない
- 達成：既存の金の栞と制覇証を、その瞬間だけ出す
- 二人：県ページ末尾の「ふたりの記録」へ降ろし、競争順位にはしない

実装境界は小さいです。県棚の既存判子グリッドを再利用し、`rallyOptIn[pref]` と表示モードだけを足します。

### B. 県鳥がほどける

- 置き場所：棚の県ページ内、判子グリッドの下
- 見せる時：初訪問後に1片だけ現れ、以後は記録に応じて自然に絵がほどける
- 進捗：数値や「あとN湯」を出さず、鳥の断片だけで伝える
- 470s資産：県鳥47枚をそのまま貼らず、和紙の切り絵へ減色・再構成
- 達成：全片が揃った瞬間に鳥名と制覇証を開く

課題感は最も弱い一方、枠を数えて埋めたい人への明快さはAより落ちます。県鳥画像の再制作も必要です。

### C. 470sを「別冊」のまま残す

- 置き場所：設定の「別冊をひらく」だけ。ととのい帳の4タブは変更しない
- 見せる時：利用者が自分で別冊へ移ったときだけ
- 470s資産：県鳥・証明書・残り数・全国進捗をそのまま維持
- 連携：ととのい帳の訪問データを470sが読む一方向同期を将来検討
- 二人：夫婦比較はととのい帳の記録タブに残し、ラリーと混ぜない

記録ファーストを最も強く守れますが、アプリ間移動と二重保守が残ります。紗也乃さんが現状の470sで十分なら、これが最小コストです。

## 採否

- **採用候補：A**。明示opt-inで進捗表示の原則を局所的に緩める。
- BはAの達成演出として後付け可能。ただし47枚を一括移植しない。
- Cは比較対照として維持。Aの実機検証で課題感が戻るならCへ退く。

## 実機検証の観点

1. 帳を開いた直後に未達タスクを感じないか。
2. 棚を開いた紗也乃さんが、説明なしで「めぐりをひらく」を見つけられるか。
3. 県ページの残り数を見た後、記録そのものの価値が下がらないか。
4. 達成前に金が見えないか。
5. 夫婦比較が勝敗表示に見えないか。

`.proof-*` はレビュー注記としても画面内に置いていません。3カット内はすべて製品候補UIです。
