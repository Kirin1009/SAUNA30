### 竜泉寺 / 制作メモ

- 一次資料: [公式・お風呂](https://www.ryusenjinoyu.com/moriyama/furo/)（2026-09-21閲覧）。バズーカロウリュサウナの存在・名称を確認。
- 目視資料: 同ページ掲載の[公式サウナ写真](https://www.ryusenjinoyu.com/moriyama/wp_moriyama/wp-content/themes/mori_wp/img/furo2412/bazooka.jpg)。矩形の天井側ダクトに丸い送風口が並ぶ構造、段床の木製ベンチ、柵越しのサウナストーンを確認。写真はURL上2024年12月系の掲載素材で、現在の全設備配置・台数の証拠にはしない。
- 主役: 機械の熱風を受ける体験。水風呂を主役にした新岐阜とは構図を分ける。
- 創作: 人物、腰タオルの藍模様、気流・湯気の線、ダクト・柵・人物を一画面へ収める遠近とトリミング。送風口は一部だけ描き、総数やストーブ総台数は表現しない。熱風は可視化表現で、火炎・新設備の描写ではない。
- 表記: 「竜泉寺の湯」「名古屋守山本店」「熱風」。分店は依頼で指定されたa9に従う。別店舗を意図していた場合は承認前に差し戻す。

### みのり / 制作メモ

- 一次資料: [公式・サウナ](https://yudocoro-minori.com/sauna/)（2026-09-21閲覧）。男性の足湯ととのいスペース、アディロンダックチェア、木々を感じる外気浴を確認。
- 目視資料: 同ページ掲載の[公式足湯写真](https://yudocoro-minori.com/wp-content/uploads/2022/06/300ce5b33c0d24b313afe1afb4e6b7b6-1024x683.jpg)。広い肘掛け・傾いたスラット背もたれの椅子が浅い足湯内に置かれ、不整形の石床が見えることを確認。
- 主役: 足元を温めながら休む姿勢。新岐阜の寝水のように体を浴槽へ沈めない。
- 創作: 人物の休息姿勢、木の枝の位置、風の線、石の並び、足元の波紋。足湯の面は藍の記号表現。実際の水深・浴槽形状・椅子数を示す図ではない。有料岩盤浴エリアのハンモック等を混ぜていない。
- 表記: 「湯どころ」「みのり」「岐南」。描写の根拠は男性側の設備であり、女性側も同設備だとは案内しない。

## 比較・受け入れ

`compare.html` を開くと三印を同じ寸法で比較できる。棚156px、帳296px、押印完了296pxをそれぞれ独立した段に配置。画面幅が狭い場合は印を縮めず段を折り返す。原寸PNGへのリンク付き。外部フォント・ライブラリ・通信・保存は不要。

検品画面は `comparison-shelf.png` / `comparison-book.png` / `comparison-completion.png`（各1280 × 720）。撮影時に見えている前後の段も含む。厳密な表示寸法の確認にはPNGを画面に合わせて縮めず、HTMLをブラウザ100%表示で開く。検証結果は `verification.md`。

**原寸と縮小を一枚に並べた確認画像**は `g4-size-comparison.png` / `a9-size-comparison.png` / `g6-size-comparison.png`（各2180 × 1260）。原本台紙 `original-compare.html?facility=g4`（またはa9/g6）は1254/156/296/296pxを並列に固定し、小画面では意図的に横スクロールする。通常の小画面閲覧には上記 `compare.html` を使う。

- 棚: 施設名と人物の姿勢が区別できること。細かな「熱風」等の文字は主情報にせず、画像外にも正式施設名を置く。
- 帳/完了: 顔の表情、風の方向、足湯と椅子の関係を読み取れること。
- 三印: 同一の朱・藍・生成りと太い枠の系列でありながら、冷たい水面/熱風/足湯休息が同じ構図になっていないこと。
- アクセシビリティ: 実装時も施設名のテキストと適切な代替文を残す。絵の文字や色だけで施設・訪問回数を伝えない。
- 10回目: 絵全体を金へ変える決裁を維持。別の金印を重ねたり分離したりしない。既存実装の色変換が生成り地まで潰さないかは組み込み時にココが確認する。今回のPNGは通常版のみ。

公開は俊輔さんの明示承認待ち。完成画像を未承認のまま本体へ置き換えない。未制作施設は既存 `facSeal()` のまま維持する。
