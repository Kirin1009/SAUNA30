# ととのい帳 写真スキン素材 第5弾

Issue #24 の量産依頼に基づく、一訪問一枚の写真表示用素材です。`totonoi/index.html`への組み込みは含みません。

## 納品物

| ファイル | サイズ | 用途 |
| --- | ---: | --- |
| `polaroid-frame.webp` | 640x760 | 写真の上に重ねる縦型ポラロイド枠。中央窓と外周は透過。 |
| `tape-washi-a.webp` | 320x96 | 生成りの和紙マスキングテープ。 |
| `tape-washi-b.webp` | 280x96 | 薄い苔色の和紙マスキングテープ。 |

## レイヤー順

下から順に重ねます。

1. 写真を中央窓に合わせて`object-fit: cover`で配置する。
2. `polaroid-frame.webp`を写真より前へ置く。
3. マステはいずれか1枚だけを最前面へ置く。
4. 影は画像へ焼き込まず、写真セット全体へ実装側で薄く付ける。

## 配置メモ

- ポラロイド枠は正面向きのため、写真と枠を同じコンテナ内でまとめて回転させる。
- 「きょうの欄」は`-1deg`から`1deg`程度に抑え、写真を読めることを優先する。
- 生成りマステは左上から右下へ`-4deg`前後、苔色マステは右上から左下へ`3deg`前後を推奨する。
- マステは実寸の40〜55%程度を写真上辺へ重ね、両端が枠から少しはみ出す位置に置く。
- 過去行の小サムネではマステを省略してよい。訪問詳細の大判表示で質感を見せる。
- 文字、金、影は素材に含めていない。写真の色と御朱印を主役にするため、和紙の繊維は低コントラストにした。

## 生成と書き出し

- OpenAI組み込み画像生成で、均一なクロマキー背景上の無地和紙素材として生成した。
- 生成結果の透明領域を維持し、指定寸法へリサイズ後、透過WebPとして書き出した。
- ポラロイドの中央窓は完全透過。写真は枠画像の下層に置く。
