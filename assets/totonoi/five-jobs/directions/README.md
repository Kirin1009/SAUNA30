## 共通仕様と境界

- 句点で締める標語、大きな明朝の扉見出し、「私の番付」を使わず短い名称にした。画像内の文字は原本のまま。
- 三印を切り抜かず全体表示する。丸い頭文字印は主役に置かない。新規試作印は追加していない。
- 絵のタップで拡大、閉じる・Escapeで復帰。Cの棚では展示する印を切り替えられる。
- 順位は総合と5軸の切替を操作できる。ただし並びは固定の表示fixtureで、実際の点数・集計ロジックではない。訪問数・日付・採点値は作らず省略した。
- 470sの旧採点は独立した開閉欄。実データは読み込まない。整い★は採点外と明示。
- 整い★0.5刻み、施設の収録値と本人の実測を並べる決定は維持。ただし今回の2画面に入力・施設ページは含めず、改めて実装・検証したとは扱わない。
- 非訪問日にも最新の一印を帳の主役にする決定、10回目に絵全体を金にする決定も変更しない。金変換は今回実装しない。
- 「表示見本」「順位は配置見本」等の注記とA-C比較ナビはレビュー専用。製品の最終ナビ提案ではない。
- 外部フォント・表示用ライブラリなし。既存の日本語ローカル書体を使用。素材・光・奥行きはCSS。tokens.cssに色・書体を分離。
- 390pxでは各画面844pxに収まる。狭い幅で折り返し、広い幅では480pxを上限に中央配置。旧採点を開いた場合は縦に伸びる。デスクトップ専用UIを提案するものではない。
