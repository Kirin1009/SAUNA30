施設ページへの連続アクセスは途中からWAFチャレンジとなりました。依頼どおり、`#map[data-lat][data-lng]` を実ブラウザで読めた施設だけを `facilities.json` に含めています。座標を取れなかった72湯は推測やジオコーディングで補完せず除外しました。

## 項目

- 必須：`sid`, `name`, `pref`, `city`, `lat`, `lng`, `ikitai`
- 一覧に存在した場合：`fee`, `m`, `w`
- 施設ページに存在した場合：`hours`, `off`, `hp`
- `m` / `w`：`[サウナ室温度, 水風呂温度, 外気浴, ロウリュ]`

値が無い項目は省略しています。`totonoi/catalog.js` は変更していません。

## 検証

- JSON構文
- `sid` 重複なし
- `lat` は20–46、`lng` は122–154の範囲
- 全件が現行カタログ未収録の`sid`
- 各都県の一覧順位11–30位からのみ抽出

残り72湯は同じ一覧スナップショットを基準に、WAFの制限が解けた回で追補できます。今回の68湯は、そのまま取り込み可否を判断できる独立データです。
