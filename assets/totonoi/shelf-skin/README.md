# 棚タブ スキン素材

ととのい帳 alpha.4 の棚タブを、承認済みビジュアルターゲットの「木の棚に集めた御朱印」へ近づける素材一式です。

## 納品物

| ファイル | 用途 | 意図 |
|---|---|---|
| `wood-back.webp` | 棚の背板 | 淡い木肌。判子と伏せ判の輪郭を主役にするため、節を置かず、木目の明暗差を抑えています。 |
| `wood-shelf.webp` | 棚板 | 背板より濃い飴色。横方向の木目を少し強め、棚板としての厚みを感じられるトーンにしています。 |
| `deco-bonsai.webp` | 棚隅の盆栽 | 苔色の丸い葉、こげ茶の手描き線、朱の鉢。判子に似すぎないよう朱は小面積に限定しています。 |
| `deco-vase.webp` | 棚隅の一輪挿し | クリーム色の花器と一輪の山茶花。細身で、判子の並びへ入り込まない縦長のシルエットです。 |
| `deco-yunomi.webp` | 自由提案の湯呑み | 湯上がりの茶の間らしさを足す小さな脇役。盆栽・花瓶より小さく表示する想定です。 |

## 実装メモ

- 木目2種は `256x256`、lossless WebPです。上下・左右の端画素を一致させたシームレスタイルです。
- `wood-back.webp` は背板全面へ `background-repeat: repeat` で使用します。
- `wood-shelf.webp` は棚板の帯へ使用し、横木目が読めるよう縦方向へ引き伸ばしすぎないでください。
- 小物3種は `256x256` の透過WebPです。棚の隅へ1〜2点だけ置き、同じ画面ですべてを並べない想定です。
- 推奨表示幅は盆栽72〜88px、一輪挿し56〜68px、湯呑み42〜54pxです。
- 金の栞や栞掛けは含みません。既存の `ribbon-gold.webp` とリワード機能の設計時に組み合わせます。
