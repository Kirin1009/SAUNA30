# ととのい帳 design-v1 ビジュアルターゲット

Issue #24 コメント `5352259642` の納品物です。スタイルリファレンス v1 を、公開 alpha.27 の帳／探す／棚／記録／押印完了へ適用したときの実装ターゲットを390px幅で示します。

## 原本とカット

- `visual-targets.html`：5カットをまとめた原本。外部フォント・外部ライブラリ・ビルド工程なし
- `01-book.png`：帳。きょうの大判、再訪の幽霊判、月区切り
- `02-find.png`：探す。チップ、実カタログの地図形状、近い順リスト
- `03-shelf.png`：棚。既存木棚、伏せ判、回数バッジ
- `04-log.png`：記録。時系列と設定
- `05-stamp-done.png`：押印完了。朱と墨の役割分離

HTMLは `totonoi/catalog.js`、`totonoi/art/`、現行 `facSeal()` と同じ生成規則を参照します。判子、地図、和紙、和綴じ、ページ端、木棚、一輪挿しは新作していません。

## デザイン判断

### primaryを墨にしても沈まない

墨 `#4A3B2E` のベタ塗りを採用します。4画面から朱のボタンを外しても地味にはなりません。成立条件は色の派手さではなく、次の4点です。

1. primaryは1画面に1つだけ置く。
2. 紙との明度差、42px以上の高さ、700ウェイトで操作面を明確にする。
3. 朱は最新の判子・訪問済み印など、記録が生んだものに集中させる。
4. secondaryは紙色＋強罫、3つ目以降はリンク段へ降ろし、墨primaryと競わせない。

金の操作利用、primaryの朱残し、枠線primaryは不採用です。金を操作に使うと「積み重ねの結果」という意味が壊れ、朱を極小面積でもボタンに残すと「判子だけが着る色」という学習が曖昧になります。枠線だけでは押印完了の「閉じる」が二次操作に見えます。

### トークン表への異論

v1の方針に変更要求はありません。8段の型、4角丸、2影、3px余白系、三役書体は5画面で不足なく成立しました。

ただし実装時の解釈を2点固定します。

- `--stamp` の「判子のみ」は、UIコントロールに使わないという意味。訪問済み地図点、再訪短冊、済み印など「記録が生んだ非操作表示」は朱の側に含めます。
- ナビ選択状態は朱ではなく墨＋上罫で示します。朱を使うとタブが判子と競合します。

## カット別トークン対応

| カット | 主な適用 |
|---|---|
| 帳 | `--font-mincho`＝月見出し・施設名、`--font-mono`＝集計・日付、`--stamp-ghost`＝幽霊判、`--ink`＝固定CTA |
| 探す | `--r-chip`＝絞り込み、`--paper2`＝入力、`--map-paper` / `--map-land`＝地図、`--stamp`＝訪問済み点だけ |
| 棚 | `--plank`＋既存wood素材、`--r-control`＝判子セル、`--font-mono`＝回数、伏せ判は現行 `facSeal()` |
| 記録 | `--font-mono`＝日付・点数、`--sh-paper`＝時系列カード、primaryは手動記録だけ、設定はsecondary |
| 押印完了 | `--stamp`＝148px判子・再訪短冊、`--ink`＝閉じる、`--paper`＝シート、`--rule2`＝secondary |

## 実装への逆算順

1. 色・書体・型・余白・角丸・影の変数をv1へ揃える。
2. `.btn.primary`、ナビ選択、選択チップから朱を外す。
3. 日付・点数・温度・回数を等幅へ統一する。
4. 大見出しと施設ページ施設名だけを明朝へ移す。
5. 紙カードのpaddingを15px、セクション間を24pxへ揃える。
6. 既存素材・判子を変更せず、面の色差と2影だけで階層を再構成する。

## 確認方法

リポジトリルートでHTTPサーバーを起動し、`/assets/totonoi/design-v1/visual-targets.html` を開きます。`file://` 直開きでは `catalog.js` の参照がブラウザ制約で止まる場合があります。

検証対象は320 / 375 / 390 / 414 / 768pxです。PNGは各 `.cut` を390×844pxで書き出します。
