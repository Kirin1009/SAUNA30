# ととのい帳 — スタイルリファレンス v1

> 和紙の帳面に、朱の判子が一つずつ増えていく。奥まった湯屋の暖色、こげ茶の墨、報酬にだけ許された朱。

**テーマ：** ライト（単一テーマ。ダークは持たない）

ととのい帳は**御朱印帳の言語**でできている。地は和紙、文字は墨のこげ茶、そして**朱は判子だけが着る色**。画面は「紙の重なり」で階層をつくり、影で持ち上げない。見出しには明朝を立て、UIと本文は丸ゴシックが担う——この二役の線引きがこのアプリの声を決める。装飾は多くない代わりに、**押した判子そのものが装飾**になる。育つのは絵ではなく記録のほうだ。

すべてシステムフォント・静的画像のみで成立させる（外部フォント／外部ライブラリ／ビルド工程は禁止。CLAUDE.md 絶対ルール3）。

## トークン — 書体

**三役制。この境界は厳格に守る。** いま丸ゴシック1本で全部やっているのが「格が出ない」原因で、年次扉で明朝を使ったときだけ急に格が上がったのが根拠。

### 明朝 — 格の担当 · `--font-mincho`

```
'Hiragino Mincho ProN','Yu Mincho','Noto Serif JP',serif
```

- **使う場所**：年次扉の年号、証書、制覇・栞の祝いシート、帳の大見出し、施設ページの施設名
- **使わない場所**：ボタン、ラベル、本文、リスト行
- **サイズ**：22 / 32 / 46px（`heading-sm` 以上のみ）
- **字間**：`.02em`（和文の明朝は詰めない。Dittoの `-0.01em` は欧文の作法なので**輸入しない**）

### 丸ゴシック — UIと本文 · `--font-round`

```
ui-rounded,'Hiragino Maru Gothic ProN','Yu Gothic',sans-serif
```

- **使う場所**：ボタン、タブ、本文、リスト行、フォーム、通知——**明朝と等幅以外のすべて**
- **太さ**：400 本文 / 700 強調 / 800 見出し相当
- 手描きアイコンの世界観と地続きなのはこの書体。ここは動かさない

### 等幅 — 数と日付 · `--font-mono`

```
ui-monospace,monospace
```

- **使う場所**：日付、点数、温度、回数、収録数、版表記
- **理由**：桁が揃うと「記録」に見える。既に `.pe-date` `.stats b` `.td` で使っており、これを規則に昇格させる
- **字間**：`.05em`

### 型スケール（23種類 → 8段）

| 役割 | サイズ | 行間 | 書体 | トークン | 用途 |
|---|---|---|---|---|---|
| micro | 9px | 1.4 | 等幅／丸ゴ | `--t-micro` | 版表記、判子内の市町村 |
| caption | 10.5px | 1.5 | 丸ゴ | `--t-caption` | 補足、注記、`.settext` |
| body-sm | 12px | 1.6 | 丸ゴ | `--t-body-sm` | リスト行、チップ、副次情報 |
| body | 13.5px | 1.7 | 丸ゴ | `--t-body` | 本文、ひとこと、ボタン |
| lead | 15px | 1.6 | 丸ゴ | `--t-lead` | 施設名（リスト）、シート見出し |
| heading-sm | 22px | 1.4 | **明朝** | `--t-heading-sm` | セクション大見出し |
| heading | 32px | 1.3 | **明朝** | `--t-heading` | 証書・祝いシートの主文 |
| display | 46px | 1.1 | **明朝** | `--t-display` | 年次扉の年号 |

現行の 9.5 / 10 / 11 / 11.5 / 12.5 / 13 / 14 / 14.5px はすべてこの8段のいずれかへ丸める。**中間値の新設は禁止。**

### 余白スケール

| 名前 | 値 | トークン | 用途 |
|---|---|---|---|
| xs | 3px | `--sp-xs` | アイコンと文字の間 |
| sm | 6px | `--sp-sm` | 行内の要素間 |
| md | 9px | `--sp-md` | 要素間の標準 |
| lg | 15px | `--sp-lg` | カード内の段落間、カード内側 |

**密度は「ゆったり」へ寄せる。** 現状はやや詰まっている。カード内側は 12px → **15px**、セクション間は 15px → **24px** を標準にする。

### 角丸（12種類 → 4種）

| 要素 | 値 | トークン |
|---|---|---|
| 紙（カード・シート・ページ） | 10px | `--r-paper` |

| 名前 | 値 | トークン | 用途 |
|---|---|---|---|
| 紙の段差 | `0 1px 3px rgba(74,59,46,.15)` | `--sh-paper` | 重なった紙の縁 |

- **カード内側：** 15px

## 装飾とUIの境界（今回いちばん重要な変更）

**朱 `--stamp` は判子だけが着る。**

いま `--stamp` は**判子の朱**と**primaryボタン**の両方に使われている。押印完了画面では、大判の判子が朱、その真下の「閉じる」も朱で、**画面に主役の赤が2つ**ある。判子は報酬で、ボタンは操作。同じ赤を着せると押印の朱が「ただのボタン色」に見えて価値が下がる。

したがって：

- **primaryボタン＝墨 `--ink` のベタ塗り＋紙色の文字。** 落ち着いていて、和の帳面に馴染み、朱と喧嘩しない
- **朱＝判子・朱印・済み印・「◯回目」の短冊・訪問済みの地図点**——**記録が生んだものだけ**。逆に言えば、押せるもの（ボタン・タブ・選択中のチップ）には出さない
- **金 `--gold` ＝常連10回・県／地方／全国制覇・栞。** 「積み重ねの結果」にだけ許される。進捗の途中では絶対に出さない（進捗の事前表示はしない原則と対）
- **藍・緋・苔・地図色は領域を指すためだけ**に使い、ボタン・バッジ・状態表示には出さない
- **ナビの選択状態は墨＋上罫**で示す。朱にするとタブが判子と競合する（design-v1の検証で確認）

Dittoの "Decoration vs Interface Color Boundary" 節と同じ規律だが、**橋渡し役の色を置かない**点が違う。ととのい帳では朱は最後まで報酬側に留まる。

## コンポーネント

### primaryボタン
主操作。`--ink` ベタ塗り、文字 `--paper`、`--r-control` 8px、内側 `9px 15px`、`--t-body` 丸ゴシック700、**影なし**。**1画面に1つまで。**

墨のベタ塗りで沈まないことは design-v1 のビジュアルターゲット（`assets/totonoi/design-v1/`）で実証済み。成立条件は色の派手さではなく**高さ42px以上・700ウェイト・紙との明度差**の3点で、secondaryを紙色＋強罫へ降ろし、3つ目以降をリンク段へ落として競わせないこと。

### secondaryボタン
副操作。地 `--paper`、枠 `1px solid --rule2`、文字 `--ink`、同じ角丸と内側。primaryと横並びにするときは必ずこの組み合わせ。

### リンク段（`.linkrow`）
ボタンにするほどでない導線。文字 `--t-caption`、色 `--ink-mid`、下線。**3つ目以降の選択肢はここへ降ろす**（alpha.27の「この湯の別の日も記す」がこの型）。

### 紙カード（`.sect` / `.pg`）
地 `--paper`、角丸 `--r-paper` 10px、内側 `--sp-lg` 15px、枠 `1px solid --rule`、影は `--sh-paper` まで。見出しは `.eyebrow`。

### eyebrow（小見出し）
`--t-micro` 9px、丸ゴシック700、字間 `.18em`、色 `--ink-mute`。カードの最初の行。**装飾ではなく分類のラベル**として控えめに。

### 判子（御朱印）
`facSeal()` が生成。形＝施設タイプ、中央＝頭文字、肩＝市町村、モチーフ＝実データ由来。色は `--stamp`、常連は `--gold`。かすれは共有フィルタ `#sealtex` 1個。**傾きはidハッシュで決定的**（毎回変わらない）。伏せ状態は形と「？」だけ見せる。

### 幽霊判
再訪の過去分。`--stamp-ghost`、サイズ80px、最新だけ126pxで濃く。**主役は常に最新の一印**。

### チップ（絞り込み・観測タグ）
`--r-chip` 999px、地 `--paper2`、選択中は地 `--paper` ＋枠 `--rule2`。`--t-body-sm`。

### 入力欄
地 `--paper2`、枠 `1px solid --rule`、角丸 `--r-control`、`--t-body`。プレースホルダ `--ink-mute`。

### 通知（`notify`）
下部に出る短冊。成功は `--ok`、失敗は `--stamp`——**ここは朱の例外**（エラーは報酬ではないが、赤以外に代わりがない）。要検討事項として残す。

## Do / Don't

### Do

- 明朝は22px以上の見出し・年号・証書だけに使い、丸ゴシックはUIと本文だけに使う。**この境界を跨がない**
- 数・日付・温度・回数は等幅で組む。桁が揃うと記録に見える
- 面の分離は紙の色差でやる。影は「紙の段差」と「押印」の2つだけ
- 朱は判子に予約する。操作の色は墨。**境界は「押せるかどうか」**——押せないもの（判子・短冊・済み印・訪問済み点）は朱、押せるもの（ボタン・タブ・チップ）は墨
- 金は積み重ねの結果（常連・制覇・栞）にだけ出す
- 3つ目以降の選択肢はボタンではなくリンク段へ降ろす（完了画面の「終われる感じ」を守る型）
- 判子の傾き・かすれは idハッシュで決定的にする。再描画で暴れさせない
- 新しい値が要るときは、この文書を先に直してから実装する

### Don't

- 外部フォント・外部ライブラリ・ビルド工程を入れない（絶対ルール3）。明朝も丸ゴシックも**システムフォントで足りている**
- ボタンをピル（999px）にしない。ピルはチップとバッジだけ
- primaryボタンを朱にしない。1画面に主役の赤を2つ置かない
- ナビの選択中タブを朱にしない
- 型スケールの8段の間に中間値を作らない（9.5pxや11.5pxを復活させない）
- 進捗の途中で金を出さない（栞・制覇は達成の瞬間まで伏せる）
- 領域色（藍・緋・苔・地図色）をボタン・バッジ・状態表示に流用しない
- カードに影を足して階層を作らない
- ダークテーマを作らない（和紙の世界観が成立しない。単一テーマで通す）
- **`assets/totonoi/design-v1/` のビジュアルターゲットにある `.proof-*`（「● 報酬 ── ● 操作」の凡例）を実装へ移植しない。** これは朱と墨の分離を証拠として見せるためのモック注記で、製品UIではない（デザイン責任者による確定。`05-stamp-done.png` の枠内に写り込んでいるため誤読しやすい）

## 図版

- **県鳥パズル（`art/<slug>.webp`・47枚）／武将タイル画／家紋**：既存資産。**開くまで伏せる**のが原則で、進捗の先取り表示はしない
- **スキン素材（`totonoi/art/`）**：和紙テクスチャ、和綴じ帯、紙造作、ポラロイド枠、マステ、木の棚、栞。原本は `assets/totonoi/<画面>-skin/`
- **ビジュアルターゲット（`assets/totonoi/design-v1/`）**：この憲法を帳／探す／棚／記録／押印完了へ適用した実装ターゲット5カット（390×844）と原本HTML。実カタログ569湯・既存 `facSeal()`・既存スキン素材で描かれており、新規意匠は含まない。**`.proof-*` はモック注記なので移植しない**
- **写真**：ユーザーの1訪問1枚。ポラロイド枠に収めて `--paper-hi` の上に置く
- 3Dレンダー・人物イラスト・写真素材の追加はしない。**画面の主役は判子と紙**

## Dittoから採ったもの／採らなかったもの

参照した `Ditto — Style Reference` に対する判断を記録しておく（同じ議論を繰り返さないため）。

**採った**
- トークン表という形式そのもの（この文書の存在理由）
- 書体の役割を厳格に線引きする規律（Interとserifの境界 → 明朝と丸ゴシックの境界）
- サーフェス2〜3段・影なしで階層をつくる考え方
- primaryは1画面に1つ
- 装飾色とUI色の境界を明文化すること

**採らなかった**
- Inter / Hedvig Letters Serif — **外部Googleフォントは絶対ルール3に抵触**。圏外のサウナで使うPWAなので、取得失敗した瞬間に別のアプリの顔になる
- `#ffe228` 蛍光イエロー、`#59e25d` 緑、`#e261e5` フクシア — 和紙の上で浮く
- 1440pxピル — 判子（丸印・角印）の幾何と正面衝突する
- 1200px最大幅・3カラムグリッド — スマホ専用アプリなので前提が違う
- 見出しの字間 `-0.01em` — 欧文の作法。和文明朝はむしろ開く
- 「装飾色がUI色を兼ねる橋渡し役」— ととのい帳では朱を最後まで報酬側に留める
